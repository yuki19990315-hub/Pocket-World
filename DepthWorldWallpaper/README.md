# DepthWorld Wallpaper — Androidライブ壁紙

Nothing Phone (4a) ProなどのAndroid向け、4モードの2.5Dパララックス壁紙アプリ（試作 v0.4.1）。

## 4つのモード

1. **写真・イラスト:** 画像1枚を選ぶと、Google ML Kitが目立つ人物・動物・物体を認識して前景を切り抜きます。背景の被写体跡は近隣画素で簡易補完。さらに「柔らかな光・星くず・木漏れ日・ネオン・夕焼けの逆光・水面の反射」の6種類（光なしを含め7選択肢）を選べます。必要なら背景・発光・前景の3層を個別に読み込んで調整できます。
2. **幻想世界:** 生成した星空と、透過した魔法の浮遊島の2つの画像＋Canvas生成の光を利用します。発光・浮遊・視差がアニメーションします。
3. **PocketWorld:** [Pocket-World](https://github.com/yuki19990315-hub/Pocket-World) の既存の8世界×2成長段階をそのまま同梱しています。自然＋文明の「成熟」では別途生成した浮遊島のドット絵を利用します。そのほかはゲームの240pxピクセルアートを浮遊する額縁として表示します。
4. **動画・AI動画（v0.3〜v0.4）:** 端末内の動画（Androidのドキュメントピッカーで選択できるもの）を入力して、次の2方式を選べます。どちらも音声を除去した短いループ壁紙です。
   - **動画＋光:** 指定した開始位置から最大8秒を20fpsで静止フレーム列に事前変換、Canvas上で無音ループ。選択した光を前後に描画し、背面動画面を少し傾き移動させます。
   - **AIで動画を分離:** 指定した開始位置から最大6秒を10fpsでフレーム列に変換し、Google ML Kitで各フレームの被写体を切り抜き、背景穴を近隣画素で簡易補完。再生時は前景が背景と逆方向に動きます。切り抜き処理はインポート時のみで、壁紙表示中には実行しません。v0.4ではマスクを前フレームと少し混ぜてチラつきを軽減。

### 動画の使い方

1. アプリの「壁紙の世界」で **動画・AI動画** を選びます。
2. 次に取り込む動画の「開始位置（0〜60秒）」と「使用する長さ（2〜8秒）」を選びます。実際の動画の範囲外なら自動調整します。AI版は6秒までです。
3. 「▶ 動画＋光でライブ壁紙にする」または「✦ 動画をAIで前景・背景に分ける」を押します。
4. スマホ内の動画を選んで、変換率が100%になるまで待ちます（AI版は時間がかかります。「中止」可能）。
5. 設定済み動画のサムネイルを確認し、再生速度（0.5〜1.5倍）、往復ループ、拡大率（100〜160%）、位置合わせ（上下左右）、6パターンの光、傾きセンサー、表示fpsを調整して「壁紙をプレビューして設定」を押します。
6. 別の動画を取り込むと保存済みの前回動画は30秒後を目安にアプリ内から削除します。「保存した加工動画を削除」でも内部フレームを消せます。**元の端末内動画には触れません。**

## 動作

- `WallpaperService.Engine` と `SurfaceHolder.lockCanvas()` によるCanvas描画
- `TYPE_ROTATION_VECTOR` → `TYPE_GAME_ROTATION_VECTOR` → 加速度センサーの順にフォールバック。端末に該当センサーがない場合はタッチのみで移動
- 相対姿勢をローパス補間。背後は移動量5%、光は12%、手前は逆方向25%を目安に移動
- 4秒周期の発光、柔らかい影、浮遊の上下動
- 奥行き0.5〜2.0倍、発光0〜100%、60/30fps、タッチの設定
- 表示中だけセンサー登録・描画。`onVisibilityChanged(false)`とSurface破棄で解除
- 画像はアプリ専用領域へコピー。写真のサーバー送信・外部アカウント・広告は不要（モデル初回取得時の通信は必要）
- **v0.2:** Google ML Kit Subject Segmentation（ベータ）によりスマホ内で自動切り抜き。モデルは初回だけGoogle Play開発者サービスがダウンロードし、取得後の画像処理は端末内で実行。光の6プリセットを追加
- **v0.3:** 動画/AI動画モード追加。`MediaMetadataRetriever`で端末内フレーム変換、動画フレームはJPEG、AI前景は透過PNGに保存。フレームのデコードは非同期・少数キャッシュで壁紙UIスレッドをブロックしない。動画ごとにローカルの保存先を切り替える。
- **v0.4:** 動画の開始秒・使用長、倍速、前後往復ループ、ズーム、上下左右の構図調整、サムネイル、保存済み加工動画の削除。前フレームのAI信頼度を17%混ぜて境界を滑らかにする暫定処理、センサーの手動OFF、Androidの省電力モード時の20fps描画制限とセンサー遅延抑制。
- **v0.4.1:** Gradle 8.11.1 Wrapperと配布ZIPのSHA-256チェックを追加。GitHub Actionsのワークフローを単独リポジトリ・サブフォルダの両方の構成に合わせて修正。アプリの実行時機能はv0.4から変更なし。

## ビルド・APKのインストール

1. Android Studioでこの `DepthWorldWallpaper` フォルダを開きます。
2. JDK 17、Android SDK Platform 35、Build Tools 35.0.0を準備します。
3. Gradle同期後、**Build > Build APK(s)** を選びます（もしくはターミナルで `./gradlew :app:assembleDebug`。Windowsは `gradlew.bat :app:assembleDebug`）。初回はGradle本体・Maven依存をダウンロードするためネット接続が必要です。
4. `app/build/outputs/apk/debug/app-debug.apk` をNothing Phoneへコピーしてインストールします。
5. アプリを開いて4モードを切り替え、「壁紙をプレビューして設定」を押します。

Gradle Wrapper（Gradle 8.11.1）を同梱しています。公式配布のwrapper JAR・Gradle ZIPのSHA-256を照合する構成です。AGP 8.9.2が要求するGradleバージョンはGoogle公式の互換表で確認済みです。

### GitHub ActionsでAPKをビルドする場合

1. `DepthWorldWallpaper` をGitHubのリポジトリに追加します。プロジェクト自体をルートにする場合は `.github/workflows/build-depthworld-apk.yml` をそのまま使えます。
2. 既存の `Pocket-World` リポジトリの**サブフォルダ** `DepthWorldWallpaper/` に追加する場合は、同梱しているワークフローを **リポジトリ直下の** `.github/workflows/build-depthworld-apk.yml` にコピーしてください。サブフォルダ内のワークフローはGitHub Actionsから認識されません。
3. ワークフローは `feature/depthworld-wallpaper` ブランチへのpushで自動実行されます。デフォルトブランチにワークフローが存在すれば、Actionsの画面から手動実行もできます。
4. 実行後にArtifactsの `DepthWorldWallpaper-debug-apk` をダウンロードします。

**注意:** 本プロジェクトをGitHubにpushしたり、実際のクラウドビルドを開始したりはまだしていません。公開リポジトリに追加する場合は、コード・画像素材も公開されます。

## 注意

- 60fpsは端末の負荷とバッテリーに影響するため、必要なら30fpsを選んでください。Androidの省電力モードが有効な間は設定値よりも描画頻度を約20fpsに抑えます。実際のfpsは端末・ホームアプリによって変わります。
- 初回に設定した端末角度が傾きの基準になります。端末を普通に持った状態で、設定画面の「傾きの中心をリセット」を押すと、次のセンサー値から基準を再取得します。
- 切り抜きは「目立つ被写体と背景の分離」です。写真から正確な深度マップを作成する技術ではありません。隠れていた背景は本来不明なため、生成AIによる高精度な補完は未搭載。被写体周辺の塗り跡が見える場合があります。
- **動画はメディアプレーヤー式ではなくフレーム列式の試作**です。動画は20fps・8秒、AI動画は10fps・6秒まで。画面描画の設定が60fpsでも動画素材そのものが60fpsになるわけではありません。長尺・高解像度・30/60fps素材再生、音声、プレビュー付きの精密トリミング、動画のハードウェアデコード、完成品質のAI切り抜き安定化は未実装です。
- AIマスクの時間的平滑化は軽い重み付き平均で、動きが速いと被写体の周囲に残像が出る場合があります。完成品質のトラッキングモデルや高品質生成AIインペインティングは含みません。
- 拡大率を下げた状態で上下左右へ大きく位置をずらすと、画像の外側に背景色が見えることがあります。必要に応じて拡大率を上げてください。
- AI動画は静止画像用のML Kit Subject Segmentationに動画フレームを1枚ずつ渡す方式です。このAPI自体は公式に静止画用であり、連続動画の自然な切り抜き品質は保証されません。被写体を認識できないフレームがあれば処理を中止して元の動画壁紙設定を維持します。
- 動画の変換には一時的なCPU負荷とアプリ専用ストレージ領域が必要です。壁紙表示中もフレーム読込とCanvas描画で電力を消費します。実機で長時間の性能・電池テストはまだ行っていません。
- ML Kit Subject SegmentationはベータAPIでGoogle Play開発者サービスが必要です。初回モデルダウンロードには通信が必要。モデルが未取得の場合、処理に失敗することがあります。再試行してください。
- PocketWorld本体との成長日数同期、ロック画面の機種別の挙動、端末での性能・バッテリーは未実装または未検証です。
- もとのサンニー用AndroidアプリとESP32ファームウェアはこのアプリと別物です。
- 元のPocketWorldピクセル画像はユーザーの既存リポジトリ由来。幻想の2枚と浮遊するピクセル島はこの壁紙用に新規生成した素材です。

## 構成

```
app/src/main/java/com/depthworld/wallpaper/
  MainActivity.kt                設定・画像読み込み・壁紙プレビュー
  WallpaperConfig.kt             設定値と世界一覧
  ImageStore.kt                  安全な画像コピー
  AutoCutout.kt                  ML Kitの被写体分離＋簡易背景補完
  LightEffects.kt                6種類の発光パターン
  VideoStore.kt                 動画フレーム抽出・AIフレーム分離・非同期キャッシュ
  ParallaxWallpaperService.kt    描画・センサー・アニメーション
app/src/main/res/drawable-nodpi/  新規生成の3枚
app/src/main/assets/pocketworld/ PocketWorldから移した既存16枚
```
