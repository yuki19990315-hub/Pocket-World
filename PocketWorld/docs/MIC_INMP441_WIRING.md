# サンニー用 INMP441 マイク — 接続・反応仕様（ハード未検証）

## 確認済み

- ユーザーの販売画像は「INMP441」「I2S」「6ピン」のモジュールを示し、基板表面に **SCK / WS / L/R / SD / VDD / GND** と印刷されている。
- INMP441のメーカー資料は24-bit I2S出力、1.8〜3.3V電源、L/R=LOWで左チャネル、HIGHで右チャネルを指定する。
- Waveshare ESP32-S3-Touch-LCD-1.28 の公式回路図Rev3ではGPIO15/16/17などが外部接続向けに出ている。ただし手元の基板リビジョン・コネクタの向き・3V3/GNDの物理位置は未確認。

## 配線の**候補**（実際の基板写真・テスター確認後に確定）

| INMP441表記 | サンニー側 | 理由 |
|---|---|---|
| VDD | **3V3**（5Vや電池直結は不可） | マイクの動作電源 |
| GND | **GND** | 共通GND |
| SCK | **GPIO15**候補 | I2Sビットクロック |
| WS | **GPIO16**候補 | I2Sワードセレクト |
| SD | **GPIO17**候補 | I2S音声データ入力 |
| L/R | **GND** | 左I2Sチャネルを選択 |

電源OFF・USBとバッテリーを外した状態で配線し、裸線やはんだブリッジがないことを確認してから通電する。**端子の位置を写真から想像して接続しないこと。** 実機基板裏面やコネクタを写した写真で確認する。

INMP441モジュールがVDD電源のデカップリングを内蔵しているかは、この画像だけでは判定できない。メーカーは0.1µFのデカップリングを指定している。必要なら部品実装を確認する。

## ソフトウェア

- `settings.py` の `ENABLE_MICROPHONE = False` が安全な初期値。接続後、GPIO候補の適合を確認してTrueへ変更する。
- `inmp441.py` はMicroPython `machine.I2S` で16kHz、32-bitステレオ受信を開始。音声は破棄し、**音量レベル0〜100だけ**保持する。録音・文字起こし・外部送信はしない。
- 取得中は `GET /api/mic` と `GET /api/state` の `audio` フィールドに最新の音量目安が表示される。`connected=true` はI2Sデータを取得できたことを示すだけで、**実際のマイクの接続検出を保証しない**。
- 長期変化（天気、街の活動、魔法の粒子）は最大1分に1回だけ世界エンジンに反映する。過度な繁殖・建築を避ける。
- 音量マッピングは仮値。PCテストを通過しているが、静かな職場での感度・ノイズ・左右スロットは実機で調整が必要。受信データが常に無音なら `MIC_SLOT = 1` の動作を調べる。
- サンニーの省電力設計に合わせ、マイクもスリープ前にI2Sを停止する（実機ディープスリープは現在安全ロック中）。

## 3つのモード演出

以前からある `world_model.observe_sound()` を活用する。

1. **自然・森・共生：** 静かなら晴れ、日常の音なら風、にぎやかなら雨。
2. **街・共生：** 活気が長く続くと住民・建物が少しずつ増える。
3. **魔法：** 大きな音を何度か受けると魔力が溜まり、まれに流れ星が発生。

水槽の世界も、静かな水面・泡・波紋で音の変化を感じられる。
